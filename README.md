## 📌 Descripción del Proyecto
**Power Chess** combina las reglas tácticas del ajedrez clásico con habilidades especiales y magias estilo RPG. En cada turno, no solo mueves tus piezas, sino que puedes gastar **Maná** para activar poderes devastadores.

### ✨ Poderes Destacados:
- 🧙‍♂️ **Mago/Torre (Rayo en Área):** Daña o elimina piezas enemigas adyacentes.
- 🛡️ **Caballo (Salto Sombra):** Se teletransporta a cualquier casilla libre del tablero.
- ⚡ **Reina (Escudo Divino):** Otorga invulnerabilidad por 1 turno a una pieza aliada.
